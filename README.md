# Environmental Tech Void Miner All Drops

A tiny Minecraft 1.12.2 client-side addon for Environmental Tech 2.0.20.1 and JEI/HEI 4.x.

It adds one category for each Void Miner type. Each category has six recipes, one per tier. Drops are indexed as recipe outputs, with base and lens chances in their tooltips using the same base values as Environmental Tech's JEI pages.

Aim: QoL for recipe-transfer handlers that can fill an entire filters.
